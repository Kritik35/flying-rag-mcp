🚀 Flying RAG MCP - Руководство администратора

Полный справочник команд для управления сервером, базой векторов и отладки.

1. Запуск и управление сервером

Основная точка входа для запуска MCP сервера.

# Основной запуск MCP сервера (для Claude Desktop/Gemini CLI)
python main.py

# Альтернативный запуск напрямую
python mcp/server.py

2. Индексация и векторизация

Команды для управления процессом превращения файлов в векторные эмбеддинги.

# Запуск фонового индексатора (следит за файлами и парсит их)
python indexer.py

# Принудительная ночная переиндексация/оптимизация (по расписанию)
python scheduler/night_job.py
Примечание: Логи индексатора записываются в data/indexer.log

3. Просмотр БД и векторов (Отладка)

Все метаданные файлов хранятся в SQLite (data/metadata.db), а сами вектора — в LanceDB (data/lancedb).

Проверка статуса файлов (SQLite)

# Сводка по статусам векторизации (сколько готово, сколько в очереди)
python -c "import sqlite3; c=sqlite3.connect('data/metadata.db'); print(c.execute('SELECT status, COUNT(*) FROM indexed_files GROUP BY status').fetchall())"

# Просмотр последних 5 проиндексированных файлов
python -c "import sqlite3; c=sqlite3.connect('data/metadata.db'); [print(row) for row in c.execute('SELECT file_name, status, chunk_count FROM indexed_files ORDER BY modified_at DESC LIMIT 5')]"

Проверка векторов (LanceDB)

# Проверка количества чанков в векторной БД LanceDB
python -c "import lancedb; db=lancedb.connect('data/lancedb'); tbl=db.open_table('documents'); print(f'Всего чанков (векторов): {len(tbl)}') "

# Тестовый семантический поиск по БД из консоли
python -c "from storage.vector_store import VectorStore; print(VectorStore().search('требования пожарной безопасности', limit=3))"

4. Тестирование проекта

Запуск автотестов для проверки парсеров и основного функционала MVP.

# Проверка парсеров (PDF, DOCX, XLS и др.)
pytest test_parsers.py -v

# Проверка основного MVP (весь цикл RAG)
pytest test_mvp.py -v

5. Настройки

Глобальные настройки путей, модели и параметров чанкинга находятся в config.yaml.

Основные параметры:
  • model: nomic-embed-text-v1-GGUF
  • lemonade_url: http://localhost:13305/api/v1/embeddings
  • Максимальный размер чанка: 150 токенов
